# AI 行业周报 · 2026 年 10 月第 4 周（10/19 - 10/25）

> 覆盖 2026-10-19 至 2026-10-25，截至 10 月 25 日北京时间 20:00；完成 13 类检索，收录 18 条经来源与日期核验的事件。以官方公告、发布记录和论文提交日期为主，过滤旧闻重发、未证实预告与融资传闻；媒体独家信息注明出处，模型性能数据按发布方评测理解。

## 1. 头部大厂

### 国内

- **豆包手机助手限制金融类应用的自动操作**（10 月 21 日）
  据澎湃新闻报道，豆包手机助手官网更新操作限制，覆盖银行、信托、支付、互联网金融及信贷类应用。已声明拒绝接入的应用继续关闭自动操作。这将资金安全、敏感信息与责任划分直接落实到手机 Agent 的执行权限边界。[凤凰网转载澎湃新闻](https://feng.ifeng.com/c/8xQP4bdd79E)。

### 海外

- **OpenAI 宣布模型及 Codex 工作流将接入 Google Cloud**（10 月 21 日）
  双方计划把 OpenAI 前沿模型和 Codex 智能体工作流引入 Model Garden，通过 Google Cloud Marketplace 采购，并支持抵扣符合条件的云消费承诺。公告还预告 Google Antigravity 和 Gemini Agent 后续支持 OpenAI 模型；本周事件是合作宣布，具体可用时间需跟进。[OpenAI](https://openai.com/index/openai-models-google-cloud/)。

- **Claude Duet 开启主动式个人智能体研究预览**（10 月 21 日）
  新应用持续跟踪已连接服务，提供晨间摘要、提醒和后台任务执行，基于 Claude Opus 5.5。预览纳入 Pro、Max 套餐的共享用量，提供 iOS、Android 与网页入口，需加入候补名单。产品重点从单次问答转向持续工作与必要时的人类确认。[Claude 官方发布](https://claude.com/resources/articles/claude-duet)。

- **ChatGPT 推出锁定聊天**（10 月 20 日）
  用户可以用四位账户 PIN 或受支持的设备认证保护选定会话，使其从普通历史、置顶和搜索中隐藏。功能逐步向 Free、Go、Plus、Pro 的网页、移动端和桌面端推出；会话保留和模型改进设置保持原样。[OpenAI 更新日志](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)。

- **Claude API 发布新版本及多语言 SDK 大版本升级**（10 月 21 日）
  API 版本更新至 `2026-10-21`，新 Python、TypeScript 等 SDK 与 `ant` CLI 默认发送该版本。官方明确 SDK／CLI 同时包含独立于 API 版本的破坏性变更，并将许可证由 MIT 改为 Apache 2.0；接入方需要按迁移指南检查升级影响。[官方更新日志](https://platform.claude.com/docs/en/release-notes/overview)、[迁移指南](https://platform.claude.com/docs/en/api/migration-2026-10-21)。

## 3. 基础模型

- **MiniMax 发布 M3.1 Flash，主打低成本 Agent 工作负载**（10 月 19 日）
  官方称新版本增强编程、电脑操作和网络安全能力，在线推理速度接近前代三倍，Agent 使用成本降低约 70%。英文定价为每百万输入 token 0.15 美元、输出 0.60 美元、缓存输入 0.015 美元。发布日期以官方文章及其元数据为准，区别于部分周报的 10 月 18 日表述。[MiniMax](https://www.minimax.io/blog/minimax-m31f)。

- **Mistral 发布 Voxtral 3 语音模型与 Agent SDK**（10 月 22 日）
  新系列把转写、语音合成、推理和工具调用整合为实时流式管线，面向客服与免手持助手等多步交互。转写支持 50 多种语言，并提供说话人识别、上下文关键词等能力；支持欧盟托管 API 和自部署。日期采用官方页面 `datePublished`，与部分模型追踪站的 10 月 20 日记录区分。[Mistral](https://mistral.ai/news/voxtral-3/)。

- **Baseten 推出 mammoth-1 与 elephant-1 决策模型**（10 月 21 日）
  Base Labs 基于 Qwen3.5 后训练得到 27B 和 9B 两个模型，针对选择、评分和布尔判断返回答案概率分布。模型面向工单路由、钓鱼检测、护栏及大小模型分流，提供开放模型与 API 试用；核心价值是减少分类任务中的文本生成开销。[Baseten](https://www.baseten.co/blog/the-best-decision-models-in-the-world-mammoth-1-and-elephant-1/)。

## 4. 论文与研究进展

- **PORA 学习何时值得增加 Agent 推理预算**（10 月 19 日提交）
  方法在训练中从相同交互状态比较长、短推理的最终收益，再让控制器按剩余预算选择推理强度。作者在应用、记忆、编程、零售和数学任务上评估；在编程与数学设置中，分别以更少 actor token 和模型请求达到或超过始终长推理的效果，为逐步分配计算预算提供了可测试方案。[arXiv](https://arxiv.org/abs/2610.27119)。

- **StreamStop 用轻量预测头决定流式推理的停止时机**（10 月 20 日提交）
  方法估计提前结束思考后，动作与完整推理结果一致的概率，并通过折扣系数调整成本与一致性的权衡。作者在 WebShop、ScienceWorld 上闭环评估；WebShop 的 Qwen3.8-27B 实验中，推理 token 减少 42%，观察到的任务成功率相近。[arXiv](https://arxiv.org/abs/2610.27981)。

- **CAPSafe 区分危险动作识别与长程安全规划**（10 月 20 日提交）
  基准分别测试单步动作在具体环境中是否安全，以及面对多重家庭危险时能否生成安全长程计划。九个模型的结果显示，部分模型对危险动作的识别准确率超过 90%，长程安全规划仍更难；最高安全成功率为 78.19%，其余模型低于 65%。这提示具身 Agent 评测需要同时覆盖识别与行动序列。[arXiv](https://arxiv.org/abs/2610.28381)。

## 5. 开源项目与社区讨论

- **Anthropic 将 Agent Skills 标准捐赠给 AAIF**（10 月 22 日）
  捐赠包括名称、标识、GitHub 组织和域名，标准进入 Linux Foundation 旗下 Agentic AI Foundation 的中立治理体系。官方称已有 70 多个 Agent 平台集成，并提出版本化发布、正式提案流程与技能安全指南等路线。社区仍可直接使用和贡献，无需加入基金会。[官方公告](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)、[项目仓库](https://github.com/agentskills/agentskills)。

- **DeepSeek 开源生产推理框架 DeepInfer**（10 月 20 日）
  发布版本提供 DeepSeek-V4.1-Flash 的离线推理核心，涵盖并行调度、推测解码、结构化输出及部分确定性推理能力，支持 NVIDIA SM100 与昇腾 950。仓库同时列明完整在线服务仍需外部配套组件，部署方应按实际开放范围评估。社区讨论集中在生产经验开放及服务商复用价值。[DeepSeek 公告](https://x.com/deepseek_ai/status/2112476496283775135)、[GitHub](https://github.com/deepseek-ai/DeepInfer)、[Reddit 讨论](https://www.reddit.com/r/LocalLLM/comments/1xb710y/deepinfer_deepseek_hands_its_serving_edge_to_its/)。

- **LiteLLM 发布签名密钥轮换及信任链调整更新**（10 月 24 日）
  `v1.103.8` 和 `v1.104.6` 的官方说明要求使用新 cosign 公钥验证 Docker 镜像与 Helm 图表，旧密钥固定配置会验证失败，并移除了受信任证书包中的 eMudhra 根 CA。对网关部署者，这是需要同步检查 CI 和准入策略的供应链变更。[LiteLLM v1.103.8](https://github.com/BerriAI/litellm/releases/tag/v1.103.8)、[v1.104.6](https://github.com/BerriAI/litellm/releases/tag/v1.104.6)。

- **LangGraph JS SDK 修复重载后的中断状态回放问题**（10 月 22 日）
  `@langchain/langgraph-sdk@1.12.7` 修复 Agent Server 在线程重载后的首次提交中重新显示已解决中断、随后报 `no_such_interrupt` 的问题。修复识别历史流与当前运行边界，改善人类审批和断点恢复体验；相关前端适配包同步依赖更新。[官方发布记录](https://github.com/langchain-ai/langgraphjs/releases/tag/%40langchain/langgraph-sdk%401.12.7)。

## 6. 其他趋势

- **OpenAI 公布前沿模型训练环境的纵深防御方案**（10 月 23 日）
  公司披露强化沙箱、网络隔离、监测和高计算量红队测试，并采用前沿训练不接入互联网的政策。本周发布的是防护复盘：文中 DNS 越界事件发生在 9 月，恢复强化学习训练与内部推理发生在 10 月 1 日。持续红队测试被纳入训练能否安全继续的论证流程。[OpenAI](https://openai.com/index/securing-our-frontier-model-training-environment/)。

- **Claude Duet 发布独立动作审批、隐私与凭据隔离设计**（10 月 23 日）
  官方说明把敏感消息检查、动作意图校验和审批放在执行模型之外，凭据与 Agent 隔离。敏感发信、支付和删除等动作需要确认，证券交易与银行转账等行为保持禁止。主动式助手的竞争进一步延伸到后台运行时的权限控制、信息流约束和可审计性。[Claude 安全说明](https://claude.com/resources/articles/claude-duet-safety-privacy-and-security)。
