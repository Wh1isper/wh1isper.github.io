2026-10-26 至 2026-11-01 AI 行业动态整理

AI 行业周报 · 2026 年 11 月第 1 周（10/26 - 11/01）

覆盖 2026-10-26 至 2026-11-01；截至北京时间 11 月 1 日 20:00 检索核验，收录 20 条事件。完成 13 个方向检索，优先采用官方公告、论文首发记录和具名媒体报道，剔除跨周旧闻、日期矛盾、无明确日期及未核实的发布信息。论文日期采用 arXiv 首次提交日期，融资采用公告日期；研究结果与性能数字按作者或厂商披露口径表述。

本周主线是 AI 从模型能力扩展到可持续运行的工作流：企业服务商把模型与业务系统连接，云平台补齐 Agent 的资源管理和执行隔离，研究界则关注多智能体状态更新、视觉证据与可验证安全。交互式世界模型与复杂音效生成继续拓展多模态应用边界。

一、头部大厂

国内

  • 百度 APP 升级搜索、AI 镜头与互动应用（2026-10-30）

    百度在产品沟通会上介绍搜索框、AI 镜头、GUI 可视化和互动应用升级，推动搜索从回答问题走向多步任务交付。搜索 AI API 同步升级，提供 API、MCP、Skill 接入；报道所列每千次 4.9 元为限时活动价格。来源：中国新闻网。

海外

  • OpenAI 与 ServiceNow 扩大企业工作流合作（2026-10-28）

    双方计划把 OpenAI 模型与 Agent 接入 ServiceNow 的开发、IT 服务和安全工作流，并连接 ChatGPT、Codex 与企业业务系统。合作重点落在应用构建、请求处理与安全事务执行，体现模型供应商与企业软件平台进一步结合。来源：OpenAI。

  • Anthropic 提交拟议 IPO 的 S-1 注册文件（2026-10-26）

    Anthropic 公告已向美国 SEC 提交 S-1，拟在纳斯达克以“ANT”为代码上市。发行股数与价格区间尚未确定，注册文件尚未生效；本条记录申报进展，上市与募资结果仍待后续公告。来源：Anthropic。

  • Anthropic 扩大美国政府客户优惠与实施支持（2026-10-27）

    与 GSA 的新协议为 Claude Enterprise、Claude for Government 和 API 提供 40% 折扣，覆盖范围扩展至州、地方、部落及属地政府。公司同时推出实施支持项目，帮助公共部门把采购转化为具体业务应用；云渠道优惠将在随后数月逐步接入。来源：Anthropic。

  • Anthropic 将 AI for Science 扩展至基金会和研究机构（2026-10-28）

    项目公布与 20 家科学基金会、机构和研究团体的合作，通过免费 Claude 额度支持研究。合作范围包括基础科学、生物医学和科研公共基础设施，强调开放数据、软件及标准的产出。来源：Anthropic。

  • Gemini 支持在对话中直接预览和编辑文件（2026-10-29）

    用户可生成并修改文档、PDF、演示文稿、表格与代码，支持手动编辑、选中内容提问和让 Gemini 定向修改。PDF 能力覆盖网页与移动端，其余列出的文件格式目前主要在网页端提供。来源：Google。

国内

（本周暂无重要进展）

海外

  • Serval 宣布完成 1.5 亿美元 C 轮融资（2026-10-29）

    该轮由红杉领投，公司公告估值为 30 亿美元，累计融资达到 2.77 亿美元。资金将支持企业自动化 Agent Catalyst，以及把自动化工程师嵌入客户组织的 ProServal 服务，面向 IT、人力、财务和安全等跨部门流程。来源：公司新闻稿、交易律师 Fenwick 确认。

三、基础模型

  • Google 发布 Gemini 4 Carbon，先向可信网络防御伙伴开放（2026-10-28）

    Google 将 Carbon 定位为加强网络安全与长程 Agent 任务的前沿模型，披露了漏洞发现、利用与修复等测试成绩。开放采取分阶段方式，本周先覆盖部分防御方与 Fairwind 伙伴；开发者、企业及消费者的更广泛接入仍在后续安排中。来源：Google。

  • DeepMind 推出 Genie 4 交互式世界模型研究预览（2026-10-27）

    Genie 4 将环境画面、原生音频和互动对话共同生成，支持通过键盘及自然语言改变模拟世界。官方将其应用方向指向机器人和 Agent 训练环境及互动体验，目前先向可信测试者提供研究预览，并开放候补名单。来源：Google DeepMind。

  • ElevenLabs 上线 SFX v3 音效模型（2026-10-29）

    新模型面向单条提示中的多个声音、音乐与人声组合，厂商报告其指令遵循与音质较 SFX v2 改进。SFX v3 已在 ElevenCreative 和 ElevenAPI 提供，可用于视频、游戏及其他需要完整场景音效的创作流程。来源：ElevenLabs。

四、论文与研究进展

  • EB-MAS：把可审计的信念更新加入多智能体安全层（2026-10-28）

    论文提出显式存储 Agent 的证据性状态，通过更新算子与“认知防火墙”约束缺乏证据的状态变化，并讨论虚假共识、串谋和错误信息传播风险。其贡献是运行时状态与更新接口的设计框架，为检索、记忆、工具和同伴通信之间的安全治理提供切入点。来源：arXiv:2610.38869。

  • EVAN：用证据消融负例改善多模态推理（2026-10-29）

    研究先识别依赖视觉证据的样本，再遮蔽关键图像区域，诱导模型暴露语言先验造成的错误回答；训练时把这些回答作为有界辅助负信号。作者报告该方法在多模态推理基准上改善了模态失衡，重点在于让奖励更准确地约束视觉证据使用。来源：arXiv:2610.39237。

  • Verse：为混合多智能体场景提供语义与可达性验证（2026-10-26）

    框架以熟悉的编程语法描述车辆、无人机、地图和传感器，再编译为混合自动机，按实际到达的模式构建执行树并检查安全断言。作者报告在标准笔记本上用 90 秒验证含 7 个 Agent、37 个模式的场景；部分多智能体测试以更宽松的可达集换取速度提升。来源：arXiv:2610.35680。

  • Hy-Nomas：以连续指令和相机控制生成交互世界（2026-10-27）

    技术报告介绍采用 8B 扩散骨干的世界模型，通过动作感知因果注意力和结构化提示，在多轮交互中保留相关历史、限制动作指令的时间作用范围。作者介绍多阶段训练与蒸馏，并在论文中声明发布配套权重、代码和基准；本条以论文首次提交日期计入本周。来源：arXiv:2610.36729。

五、开源项目与社区讨论

  • GitHub Agentic Workflows 正式可用（2026-10-28）

    开发者可用自然语言 Markdown 定义仓库自动化任务，在 GitHub Actions 中处理问题分诊、文档维护、质量检查与代码评审。官方强调默认只读、沙箱执行、网络防火墙和安全输出校验，并扩展自托管运行器及多引擎选择。来源：GitHub Changelog。

  • AWS 发布 AgentCore CLI 1.0（2026-10-28）

    重建后的 CLI 统一命令结构，支持从终端管理 Agent 的运行时、记忆、身份、网关和支付等资源，也可直接通过 ID 或 ARN 操作现有资源。JSON 输出、区域选择和迁移命令使其更适合脚本化运维与持续交付。来源：AWS。

  • Vercel AI Gateway 引入 Virtual Models（2026-10-28）

    应用通过稳定的虚拟模型 ID 调用任务，实际模型、回退顺序与零数据保留配置集中在网关侧管理。团队可在不修改代码和重新部署应用的情况下切换模型配置，将模型选择从代码常量转为可管理的运行时策略。来源：Vercel。

  • Akamai 发布模型推理服务与 Agent 沙箱（2026-10-27）

    Akamai Inference 与 Akamai Agent Sandbox 分别补齐托管模型服务和隔离执行环境，把模型运行、企业数据接入与 Agent 执行边界放在同一云平台内。对企业应用而言，关注点延伸至代码能访问哪些资源，以及执行环境如何与安全治理结合。来源：Akamai。

  • HN 讨论：优秀开发者为何对 Agent 式开发保持谨慎（2026-10-29）

    围绕同名文章的讨论集中在代码责任、可验证性、技能积累与开发者对生成结果的信任。值得关注的是“如何确认系统可靠”的工程问题；该讨论提供从业者视角，其评论与热度不能作为行业整体采用率的统计依据。来源：Hacker News 讨论。

六、其他趋势

  • AI 训练偏好信号进入共同规范探索（2026-10-30）

    OpenAI 宣布将尊重网站通过 robots.txt 表达的共同训练偏好信号，计划在随后数月实施，并保留现有爬虫控制。同日发布的 IETF Internet-Draft 描述按用途标记偏好、复用现有 robots.txt 语法的方案；当前阶段是草案与厂商采纳承诺，实际约束仍依赖后续实现。来源：OpenAI 公告、IETF 草案。
