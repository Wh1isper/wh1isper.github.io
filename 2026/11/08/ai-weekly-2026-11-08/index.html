2026-11-02 至 2026-11-08 AI 行业动态整理

AI 行业周报 · 2026 年 11 月第 2 周（11/02 - 11/08）

覆盖 2026-11-02 至 2026-11-08；截至北京时间 11 月 8 日晚间，收录 21 条经来源与日期核验的事件。检索覆盖 13 个方向，优先采用官方公告、论文首次提交记录与原始社区讨论，剔除旧闻转载、无明确日期及未核实的发布与融资消息。论文结果为作者报告，产品能力与价格以对应公告为准。

一、头部大厂

国内

  • 腾讯发布混元 Hy4，强化视觉理解与电脑操作（2026-11-04）

    Hy4 引入视觉理解与 Computer Use，可结合命令行和图形界面处理跨应用任务，并针对办公、金融分析、前端和游戏开发开展专项训练。腾讯公告表示将于近期开源权重并发布系统卡片；本周确认的是模型发布与开放计划，权重开放状态须以实际仓库为准。来源：腾讯公告。

海外

  • OpenAI 介绍面向 Agent 并发开发的 Git 后端 Pando（2026-11-02）

    Pando 已支撑 OpenAI 单体仓库开发，保留 Git 协议与客户端兼容性，同时面向大量分支并发推送和高吞吐读取扩展。OpenAI 报告生产环境的推送中位延迟改善近 5 倍，每日提供接近 1 PB 的 Git 数据，展示了 Agent 规模化开发对版本控制基础设施的压力。来源：OpenAI。

  • Claude Marketplace 扩充安全、开发与创意类合作产品（2026-11-04）

    Marketplace 合作 Agent 与产品增至 25 个以上，新增方案覆盖漏洞检测、权限治理、可观测性、部署及生产力。符合条件的企业客户可将部分 Anthropic 承诺支出用于合作产品，使模型采购与应用采购更紧密地结合。来源：Claude 官方。

  • Claude 推出 Personal Finance 测试版（2026-11-05）

    用户连接银行与银行卡账户后，可查询支出、账单与余额，并生成图表或分析异常费用。功能在美国面向 Pro、Max 和 Ultra 计划逐步开放；账户访问为只读，不能转移、管理或投资资金。来源：Claude 官方。

  • Google 展示 Antigravity 化学信息学工作流（2026-11-03）

    新 Cheminformatics Skills 将文献、分子结构与本地计算工具接入 Agent 工作台，语言模型负责编排与科学推理，确定性工具执行分子计算。官方以肺癌治疗相关案例展示检索化合物、分子对分析及候选合成路线生成，重点是压缩科研数据整理与迭代流程。来源：Google DeepMind。

二、创业公司

国内

  • Kimi 开放组织管理 Admin API（2026-11-02）

    Kimi 开放平台公告上线 Admin API，支持成员、项目和推理 API 密钥管理，以及账单与用量查询。组织可以将权限、成本和入离职管理接入内部系统，减少人工控制台操作；使用前需要完成组织认证并建立相应管理密钥。来源：Kimi 官方开发者社区公告。

海外

  • Boson AI 发布全双工 Higgs Realtime Duplex（2026-11-05）

    模型可同时接收音视频、输出语音与实时面部表现，并在对话持续进行时思考、调用工具和委派后台任务。其系统按 160 毫秒切片组织多路输入输出，演示场景覆盖会议、英语辅导和免手操作工程任务，体现实时交互与异步执行的结合。来源：Boson AI。

三、基础模型

  • 百度开放 ERNIE 5.5 Flash Base 预训练权重（2026-11-05）

    模型采用稀疏 MoE，总参数 280B、每 token 激活 14B，基于 33.5T tokens 完成预训练。发布的是未经中训练和后训练的 Base checkpoint，适合领域适配、指令微调及强化学习研究；最长训练上下文为 128K，微调与推理支持 1M tokens。来源：百度文心官方。

  • Gemini Omni 1.2 Flash 正式可用，支持 15 秒视频（2026-11-05）

    新版本支持原生生成和编辑最长 15 秒的视频，加强参考素材一致性与多轮对话编辑，并在 Gemini API 和 Google Cloud 正式提供。Google 公告称价格较 Omni 1.1 下调 30%，720p 视频为每秒 0.07 美元；工作流可先低分辨率草拟，再调整细节和放大成片。来源：Google 发布公告、Google Cloud。

四、论文与研究进展

  • PGuard：利用模型内部表征进行流式安全检测（2026-11-02）

    论文提出原生、可插拔的安全模块，从模型中间层表征提取安全信号，覆盖预填充和逐 token 生成阶段。作者报告，在 SGLang 服务的百亿级以上骨干模型上，端到端额外开销为 0.82%—2.26%；研究将安全检测与推理服务的计算和同步成本共同优化。日期按 arXiv 首次提交记录计。来源：arXiv:2611.02791。

  • 预测式安全护栏的收益取决于预测如何进入决策（2026-11-02）

    研究在七个策略模型和两个安全环境中拆解“预测—行动”链路，发现更强的预测介入并不带来单调安全收益，部分设置下任务完成率下降、推理成本增加。长时程预测可靠性及预测内容能否忠实影响行动，是解释结果的关键；该结论针对文中测试环境和方法。来源：arXiv:2611.02815。

  • DR Pixel：直接检索和推理文档页面图像（2026-11-02）

    DR Pixel 以渲染页面作为检索与推理单元，面向包含图表、公式和正文的科学文档，并构建 DRPixelBench。研究进一步使用反事实贡献为训练轨迹中的步骤赋权，作者报告检索召回率约提升 15 个百分点、最终准确率提升超过 10 个百分点，为多模态深度研究提供页面级路线。来源：arXiv:2611.03097。

  • BlackSwan：在状态变更前主动寻找反证（2026-11-02）

    方法先预测行动效果，再提出可检验的失败假设，使用已有观察或不改变状态的操作寻找反证，最后决定是否执行。作者报告，相比最强基线，在 AppWorld 上开启与关闭骨干思考模式时，成功率分别提升 14.9 和 25.2 个百分点，并在 WebShop 上观察到迁移收益。来源：arXiv:2611.02950。

五、开源项目与社区讨论

  • Google 公布 Agent 开源基础设施栈与 Agent Substrate 1.0（2026-11-05）

    官方宣布将 Agent Substrate、gVisor 和 OpenRL 捐赠至 CNCF，并说明这些项目上月已获 Sandbox 接纳、正在办理加入流程。同时 Agent Substrate 达到 1.0，并在 GKE 正式可用，覆盖隔离执行、状态化循环及面向 Agent 的编排基础设施。来源：Google Cloud。

  • Netlify 通过公共 API 开放 Agent Runners（2026-11-05）

    新接口支持启动运行、发送追加提示、回答 Agent 问题、查看修改文件并取得预览部署 URL，可选择分支、模型与执行强度。当前接口提供运行与预览能力，开 PR、提交代码和发布生产版本尚未开放；进度通过轮询运行与会话端点获取。来源：Netlify Changelog。

  • Redis Iris 扩充记忆、上下文与 Agent 通信能力（2026-11-04）

    Redis 将 Iris 扩展为六项可组合能力，包括意图路由、执行手册、Agent 记忆、上下文网关、Lens 与 Agent Mesh。产品将实时应用数据、运行状态、记忆与通信放在统一基础设施中，针对重复模型调用、上下文膨胀和脆弱集成等生产问题。来源：Redis 公告。

  • AWS AgentCore 上线带来源引用的 Web Answer（2026-11-05）

    托管工具以一次调用返回经过检索与综合的答案，支持域名允许或拒绝列表及发布日期过滤，并可作为 AgentCore Gateway 的 MCP 目标、通过 IAM 认证。首发区域为美国东部弗吉尼亚北部，按工具调用计费，将搜索、获取、综合和引用链路集中为可接入能力。来源：AWS。

  • HN 讨论：Agent 记忆是否需要共同的可观测性接口（2026-11-08）

    围绕“Agent memory needs its OpenTelemetry moment”的讨论涉及记忆格式、隔离、导出和多 Agent 运行状态的观测。一部分参与者强调跨工具诊断与迁移价值，另一部分认为问题更接近分布式系统治理和项目上下文管理；该讨论呈现工程分歧，热度不等同于行业采用率。来源：Hacker News 原始讨论。

六、其他趋势

  • OpenAI 提高安全漏洞赏金并加入质量激励（2026-11-02）

    更新提高中高危及严重漏洞奖励区间，并引入报告质量、持续参与与优先活动的奖金机制。核心产品严重漏洞基础奖励最高 3 万美元，特殊严重发现叠加奖金后最高可达 17.2 万美元；计划针对软件漏洞的负责任披露。来源：OpenAI。

  • OpenAI 推出 Grid Protectors 电网协同计划（2026-11-02）

    计划与电力公司、监管机构及政策制定者合作，使未来算力园区在电网承压时降低需求，并探索现场发电、储能和需求平滑。公告提出将园区灵活性纳入建设与运营，具体可削减容量、响应速度和持续时间仍按地区安排落实。来源：OpenAI。

  • 菲律宾参议员提出 AI 自动化裁员保护法案（2026-11-08）

    据 GMA 报道，SB 2563 拟修改劳动法，对 AI 自动化造成的岗位冗余设置条件，要求提前通知、协商、再培训和岗位调配，并提高离职补偿保障。当前是提案阶段，体现 AI 劳动力影响进入更具体的劳动程序与补偿规则讨论。来源：GMA News。
